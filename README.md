# Warteg Simulator Indonesia — Foundation

Fondasi awal proyek Godot 4 untuk game Android landscape offline.

## Konfigurasi
- Godot 4.x
- 2D isometrik / 2.5D
- Resolusi dasar rancangan: 1280 × 720
- Stretch mode: `canvas_items`
- Aspect mode: `expand`
- Renderer: Compatibility (OpenGL)
- Peta: gabungan `TileMapLayer` dan sprite terpisah
- Aset: sprite terpisah untuk karakter/bangunan; atlas untuk tile dan dekorasi kecil

## Membuka proyek
1. Unduh ZIP ini dan ekstrak.
2. Buka Godot 4.
3. Import folder yang berisi `project.godot`.
4. Jalankan scene utama.

## Catatan
Fondasi ini belum berisi aset grafis final, karakter, NPC, joystick, atau sistem gameplay lengkap.
Tahap pertama hanya menyiapkan struktur dan memastikan proyek dapat dibuka.
Jangan menganggap pemeriksaan GitHub yang berhasil sebagai bukti seluruh game sudah berfungsi.

## Rencana milestone
1. Fondasi dan validasi proyek.
2. Peta dasar dan collision.
3. Karakter utama, joystick, kamera.
4. Bangunan, objek, dan NPC.
5. Interaksi dan gameplay.
6. Save/load dan pengujian APK di perangkat Android.
